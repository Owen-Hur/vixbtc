# VIX 변동 후 BTC 영향력 유효시간 분석 보고서

## 1. 분석 목적

VIX(CBOE 변동성지수)가 변동할 때, BTC 가격에 미치는 영향력이 시간이 지남에 따라 어떻게 변하는지 파악한다. 구체적으로 VIX 변동이 BTC 수익률과 유의미한 상관을 보이는 시간 구간(유효시간)을 측정한다.

### 1.1 선행 연구

Luo, Tsai & Yen (2025, SSRN)에 따르면:
- VIX 일별 변화와 BTC 일별 수익률은 강한 음의 동시적(contemporaneous) 관계가 있다 (β = -0.6772, t = -6.924)
- 시차 효과(lagged)는 유의하지 않다 — 정보 전달이 즉각적이다
- 2024년 1월 BTC ETF 출시 이후, BTC 자체 내재변동성의 영향력은 사라졌으나, VIX → BTC 관계는 유지된다

이 보고서는 해당 논문이 일별 데이터로 확인한 "동시적 관계"가 실제로 분 단위에서 어떤 시간 구조를 가지는지, 즉 VIX 변동 후 BTC가 몇 분/시간 동안 반응하는지를 측정한다.

### 1.2 분석 구간

- **전기(2020-01 ~ 2023-12)**: BTC ETF 출시 이전
- **후기(2024-01 ~ 2026-05)**: BTC ETF 출시 이후

### 1.3 분석의 진행 경과

본 분석은 두 단계로 진행되었다.

**1단계: VIX 일별 종가 기준 분석 (섹션 2~6)**
- VIX 일별 종가 확정 시점(16:00 ET) 이후 BTC 수익률을 측정
- 전기에서는 유의한 상관이 관찰되었으나, 후기에서는 상관이 사라짐
- 그러나 이 접근은 VIX를 일별 종가로만 취급했기 때문에, 장중에 이미 발생한 동시적 반응을 포착하지 못하는 구조적 한계가 있었다

**2단계: VIX 1시간봉 기준 분석 (섹션 7)**
- VIX는 실시간 지수(장중 15초 단위 갱신)이므로, 1시간봉 데이터를 확보하여 재분석
- 장중 VIX 변동 시점부터 BTC 반응을 측정한 결과, 매우 강한 상관이 확인됨

## 2. 데이터 구성

### 2.1 원본 데이터

| 데이터 | 소스 | 기간 | 단위 |
|--------|------|------|------|
| VIX 종가 | `vix_daily.parquet` | 2020-01-02 ~ 2026-05-27 | 일봉 (미국 영업일) |
| BTC 가격 | `btc_1m_24h/*.parquet` (77개 월별 파일) | 2020-01 ~ 2026-05 | 1분봉 (America/New_York) |

### 2.2 분석용 데이터 생성: `vix_btc_response.parquet`

VIX 종가 확정 시점을 기준으로, 해당 시점 이후 BTC가 얼마나 움직였는지를 계산한 파일이다.

**생성 로직:**

1. VIX는 미국 장 마감(16:00 ET)에 종가가 확정된다.
2. 각 VIX 거래일에 대해, 16:00 ET 시점의 BTC 종가(`base_price`)를 가져온다.
3. `base_price` 대비 1분 후, 5분 후, ..., 24시간 후 BTC 종가의 수익률을 계산한다.

```
btc_Xm = (btc_price(16:00 + X분) - btc_price(16:00)) / btc_price(16:00)
```

4. VIX 전일 대비 변화량(`vix_change`)과 변화율(`vix_pct`)을 함께 기록한다.

**컬럼 구성:**

| 컬럼 | 설명 |
|------|------|
| `date` | VIX 거래일 |
| `vix` | 당일 VIX 종가 |
| `vix_change` | VIX 전일 대비 변화 (포인트) |
| `vix_pct` | VIX 전일 대비 변화율 |
| `btc_1m` ~ `btc_24h` | VIX 확정 시점(16:00 ET) 이후 BTC 수익률 (16개 시간대) |
| `year` | 연도 |

**시간대 목록:** 1m, 5m, 10m, 15m, 20m, 30m, 45m, 1h, 90m, 2h, 3h, 4h, 6h, 8h, 12h, 24h

## 3. 분석 방법

시차별 상관분석(Cross-correlation)을 기본 접근법으로 사용한다. VIX 변화율(`vix_pct`)과 각 시간대별 BTC 수익률(`btc_Xm`) 사이의 Pearson 상관계수를 계산하고, 상관이 유의미하지 않게 되는 시점을 유효시간의 끝으로 판단한다.

검증 보완으로 다음을 수행한다:
- **Permutation Test**: VIX 변화율을 10,000회 랜덤 셔플하여 실제 상관이 우연인지 검증
- **Dose-Response**: VIX 변화율을 5분위로 나누어 BTC 반응이 비례하는지 확인 (ANOVA)
- **비대칭 분석**: VIX 상승일과 하락일을 분리하여 상관 차이 확인
- **Event Study**: VIX 급등/급락(1σ 초과) 이벤트 후 BTC 평균 수익률 경로 (t-test)
- **VIX 레벨별 분석**: VIX 수준에 따라 영향력이 달라지는지 확인
- **Bootstrap 95% 신뢰구간**: 상관계수의 신뢰구간이 0을 포함하는지 확인

| Q1 (VIX 급락) | +0.032% | +0.035% | +0.163% | +0.117% | +0.126% |
| Q2 | -0.044% | -0.020% | +0.031% | -0.033% | -0.019% |
| Q3 (보합) | +0.067% | +0.074% | +0.151% | +0.127% | +0.135% |
| Q4 | +0.041% | +0.048% | +0.079% | +0.097% | +0.088% |

| ANOVA p | 0.2035 | 0.6766 | 0.4483 | 0.6283 | 0.8512 |

결과: 전 시간대에서 ANOVA 유의하지 않음. 전체 후기 데이터에서는 VIX 크기에 비례하는 BTC 반응 패턴이 없다.

### 6.4 일별 종가 분석의 한계

위 결과에서 후기(2024~)에 상관이 사라진 것은 **분석 방법의 구조적 한계** 때문이다.

VIX는 미국 장중(9:30~16:15 ET)에 15초 단위로 실시간 갱신되는 지수다. 논문에서 말하는 "동시적(contemporaneous) 관계"는 같은 날 VIX가 변하면 같은 날 BTC가 반응한다는 의미이다.

그런데 이 분석에서는 VIX 일별 종가가 확정되는 16:00 ET **이후**의 BTC만 측정했다. 16:00 시점에는 장중 VIX 변동에 대한 BTC 반응이 이미 끝난 상태이므로, 장 마감 후 잔여 효과만 보게 된다. 이것이 후기에서 상관이 약하게 나온 근본 원인이다.

이 한계를 해소하기 위해, 다음 섹션에서 VIX 1시간봉 데이터를 활용한 장중 분석을 수행한다.

### 7.1 데이터 구성

VIX 1시간봉 데이터를 yfinance에서 확보했다. yfinance 기준 무료 VIX 데이터의 최대 범위는 다음과 같다.

| 5분봉 | 최근 ~60일 |

**데이터 생성 로직:**

1. 각 VIX 1시간봉 시점(예: 10:00 ET)의 VIX 종가와 전 시간(9:00 ET) 대비 변화율을 계산한다.

3. base_price 대비 1분 후, 2분 후, ..., 4시간 후 BTC 수익률을 계산한다.

```

btc_Xm = (btc_price(t + X분) - btc_price(t)) / btc_price(t)
```
