## 1. 1단계 분석 — VIX 일별 종가 기준

### 1.1 시간 구조 검토 (✅ 문제 없음)

```
16:00 ET  VIX 종가 확정, base_price(BTC) 기록
  ↓
16:01 ET  btc_1m 측정 시작
16:30 ET  btc_30m
18:00 ET  btc_2h
24:00 ET  btc_8h
다음날 16:00  btc_24h
```

VIX 종가가 확정된 **이후** BTC 반응을 측정하므로 시간 구조 자체에는 lookahead가 없다. ✅

### 1.2 분석의 구조적 한계 (보고서가 스스로 인정함)

보고서 섹션 6.4에서 올바르게 지적했다:

> "이 접근은 VIX를 일별 종가로만 취급했기 때문에, 장중에 이미 발생한 동시적 반응을 포착하지 못하는 구조적 한계가 있었다."

VIX는 장중 실시간으로 움직이고, BTC는 그 움직임에 **즉각** 반응한다. 16:00 종가가 확정될 무렵에는 이미 장중에 VIX-BTC 상호 반응이 완료된 상태다. 따라서 16:00 이후만 보면 "잔여 효과"만 측정하는 셈이다.

→ **이 한계는 보고서에서 명시되었으므로 방법론 오류가 아니라 범위의 한계다.**

### 1.3 다중검정 문제 (⚠️ 미보정)

**문제**: 16개 시간대(`btc_1m` ~ `btc_24h`)에 대해 각각 독립적으로 Pearson 상관 검정을 수행했으나, 다중검정 보정을 적용하지 않았다.

**왜 문제인가**: 아무 관계 없는 16개 지표를 검정해도 5% 확률로 각각 유의하게 나올 수 있다. 16개를 동시에 검정하면 적어도 하나가 우연히 p < 0.05로 나올 확률은 1 - (0.95)^16 = **56%**에 달한다.

**Bonferroni 보정 기준**: α = 0.05 / 16 = **0.003125**

실제 검토 결과 후기(2024~) 데이터의 경우 Bonferroni 보정 적용 시:
- 16개 시간대 모두 유의 없음 → 보고서 결론("후기 전체 상관 없음")은 유지
- 전기(2020~2023)는 r값 자체가 -0.17 수준으로 충분히 커서 Bonferroni 보정 후에도 유의

→ **결론 자체가 뒤집히지는 않지만, 검정 절차는 개선 필요.**

### 1.4 VIX 18~25 구간 조건부 분석 (⚠️ 과도한 분류)

보고서는 후기 데이터를 VIX < 18 / 18~25 / ≥25 세 그룹으로 나눠 각각 16개 시간대를 검정했다. 이는 총 48번의 검정이다. Bonferroni 보정 기준은 α = 0.05/48 = **0.00104**가 되어야 한다.

VIX 18~25 구간에서 나온 유의한 결과들(p = 0.002~0.03 수준)은 이 기준을 일부 통과하지 못할 가능성이 있다. Permutation Test(10,000회)로 재확인한 것은 적절하지만, 보고서에서 이 점을 명시하지 않았다.

### 1.5 VIX ≥ 25 구간 (⚠️ 표본 부족)

n = 38은 Pearson 상관의 신뢰할 수 있는 추정에 필요한 최소 표본(통상 n > 30)에 가까스로 도달한다. 이 그룹의 결과는 참고 수준으로만 해석해야 하며, 보고서도 "판단 보류"로 처리했다. ✅

## 2. 2단계 분석 — VIX 1시간봉 기준 ❌

이 분석에서 가장 심각한 오류가 발견되었다.

### 2.1 Lookahead Bias — 1시간 선행 편향

**yfinance 1시간봉 bar의 timestamp 관례:**

```
timestamp = 10:00  →  해당 바는 10:00~11:00 사이 데이터
                       close는 11:00에 확정되는 값
```

**현재 분석 코드의 계산 방식:**

```python
# vix_1h_btc_response.parquet 생성 로직
vix_pct = (vix[t] - vix[t-1h]) / vix[t-1h]   # t=10:00 close 사용
base_btc = btc[t]                               # t=10:00 BTC 가격
btc_1h = btc[t+1h] / btc[t] - 1               # 이후 BTC 수익률
```

**문제의 구조:**

```
10:00 ─── BTC base_price 기록 (이 시점에 알 수 있는 것)
  │
  │     [10:00~11:00 사이 VIX 움직임]
  │
11:00 ─── VIX close(t=10:00 bar) 확정  ← 이 값을 10:00에 사용!
  │
  │     BTC 반응 측정(btc_1h = 11:00 BTC)
```

10:00 시점에서 `vix_pct`를 계산하려면 `vix[t=10:00]`의 close가 필요한데, 이 값은 **11:00에야 확정**된다. 즉 1시간 미래 데이터를 사용하는 **Lookahead Bias**다.

### 2.2 수치로 확인된 Bias의 크기

원본(biased)과 수정본(corrected, signal을 +1h 시프트)의 상관계수 비교:

| 시간대 | 원본 r (biased) | 수정 r (unbiased) | 차이 |
|--------|-----------------|-------------------|------|
| btc_1m | -0.0829 * | -0.0017 (NS) | +0.0812 |
| btc_5m | -0.2095 * | -0.0193 (NS) | +0.1901 |
| btc_10m | -0.2203 * | +0.0011 (NS) | +0.2213 |
| btc_30m | -0.3278 * | +0.0228 (NS) | +0.3506 |
| **btc_1h** | **-0.4653 \*** | **+0.0152 (NS)** | **+0.4806** |
| btc_2h | -0.3396 * | +0.0026 (NS) | +0.3422 |
| btc_4h | -0.2582 * | +0.0031 (NS) | +0.2613 |

**Lookahead를 수정하면 전 시간대에서 상관이 완전히 소멸한다.**

보고서에서 "피크 1시간, r = -0.465"라고 보고한 값은 **1시간 lookahead bias가 만들어낸 허상**이다.

### 2.3 이 오류의 의미

보고서 섹션 8.1 최종 결론에서:

> "일별 종가 분석에서 후기에 상관이 사라진 것은 VIX → BTC 관계가 없어진 것이 아니라, 장 마감 후 잔여 효과만 측정했기 때문이다. 장중 VIX 변동을 기준으로 측정하면 ETF 시대에도 매우 강한 관계가 존재한다."

이 결론은 **잘못되었다.** 1시간봉 분석에서 나온 "매우 강한 관계"는 lookahead bias의 산물이며, 실제 관계는 존재하지 않는다.

## 3. VIXY 1분봉 분석 (`vixy_effective_duration.py`, `vixy_btc_analysis.py`)

### 3.1 시간 구조 검토 (✅ 기본적으로 문제 없음)

```python
vixy_5m_pct = vixy['vixy'].pct_change(5)  # 직전 5분간 VIXY 변화율
# t 시점에 이미 확정된 값 (5분 전 ~ 현재)
base_btc = btc[t]                         # t 시점 BTC
btc_1m = btc[t+1] / btc[t] - 1           # t 이후 BTC
```

VIXY 1분봉은 t 시점에 이미 확정된 데이터이므로, t 이후 BTC를 측정하는 것은 시간적으로 올바르다. ✅

### 3.2 중복 관측치 문제 (⚠️ 서술 필요)

VIXY 분석에서는 중복 제거(30분 이내 이벤트 deduplicate)를 수행했으므로 이벤트 간 겹침은 줄었다. 그러나 Mean Path를 계산할 때 각 이벤트 이후 120분 경로를 추적하는데, 인접 이벤트들이 30분 이상 떨어져 있어도 경로가 겹칠 수 있다. 이는 t-test의 독립성 가정을 약하게 위배한다.

다만 이벤트 수(Spike 516건, Drop 520건)가 충분하고, 효과 크기가 명확하므로 결론에 치명적 영향은 없다.

### 3.3 VIXY ≠ VIX (⚠️ 반드시 명시 필요)

VIXY(ProShares Short-Term VIX ETF)는 VIX를 직접 추적하지 않는다. **단기 VIX 선물 롤(roll)**을 추적하며, contango 환경에서 지속적인 음의 롤 수익(roll decay)이 발생한다.

따라서 VIXY 분석 결과를 VIX 분석 결과와 동등하게 해석하면 안 된다. VIXY는 VIX의 방향성을 대략 추적하지만, 수익률 규모와 타이밍에 체계적 편차가 있다. 보고서에서 이 차이를 언급하지 않았다.

## 5. 결론

vix_duration 분석은 두 단계로 나뉘며, 각각의 평가가 완전히 다르다.

**1단계(VIX 일별 종가)**: 시간 구조는 올바르고, 전기/후기 결론도 데이터가 지지한다. 다중검정 미보정이라는 절차적 문제가 있으나 결론 자체를 뒤집지는 않는다.

**2단계(VIX 1시간봉)**: **1시간 Lookahead Bias**가 존재한다. yfinance 1h bar의 close를 해당 timestamp(바의 시작)에 사용했기 때문에, 실제로는 1시간 후에야 알 수 있는 VIX 값으로 현재 BTC 반응을 계산한 것이다. Lookahead를 수정(+1h shift)하면 상관계수가 -0.46 → 0.015 수준으로 완전히 소멸한다. 보고서의 핵심 결론인 "ETF 시대에도 장중 VIX-BTC 관계는 매우 강하다"는 이 편향에서 나온 것이므로 **성립하지 않는다.**

slope_change와 동일한 결론에 도달한다: VIX 기반 장중 BTC 방향 예측은, 올바른 시간 구조로 측정하면, 유의한 관계가 없다.
