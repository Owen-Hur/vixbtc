# VIX slope_change 방향 예측 검증

> 최종 업데이트: 2026-06-02 (T-day 시간축 적용)
> 핵심 질문: **"VIX slope의 일별 변화량이 BTC 방향을 예측할 수 있는가?"**
> **최종 결론: 모든 측정에서 적중률 ≈ 50%. 시차 예측력 없음.**

---

## 시간축 정의 — T-day

vix_duration 분석과 동일한 **T-day 시간축**을 사용한다.

```
T-day 0:00  ≡ 절대 16:16 ET (slope_change(T) 확정 직후)
T-day 17:14 ≡ 절대 익일 09:30 ET (다음 미국 시장 개장)
T-day 23:43 ≡ 절대 익일 15:59 ET (다음 미국 시장 마감 직전)
```

slope_change(T)는 T-day 0:00 직전(절대 16:15)에 확정되므로, T-day의 모든 측정 시점(t > 0:00)에서 lookahead-free로 사용 가능하다.

## 핵심 결과

### 다음 장중 적중률 (T-day 17:14 → 23:43)

| 구간 | n | 적중률 | binomial p |
|------|----|--------|-----------|
| IS (2024-01~2025-10) | 457 | **50.5%** | 0.852 |
| OOS (2025-11~2026-04) | 123 | **50.4%** | 1.000 |
| ALL | 580 | **50.5%** | 0.836 |

→ 세 구간 모두 무작위 수준 (binomial test 통과 못함).

### T-day 윈도우 분 단위 (0:00 ~ 17:14, 1,035개 시점)

| 항목 | ALL 구간 |
|------|---------|
| 평균 적중률 | ~47% |
| 가장 강한 음의 r | -0.06 ~ -0.09 (NS) |
| p < 0.05 시점 | 단편적 |

→ 어느 호라이즌에서도 통계적으로 유의한 예측력 없음.

### |slope_change| 크기별 (ALL 구간)

| |sc| 범위 | n | 적중률 |
|----------|----|--------|
| < 0.3 | 317 | 51.4% |
| 0.3~0.5 | 104 | 48.1% |
| 0.5~1.0 | 112 | 50.9% |
| 1.0~1.5 | 25 | 48.0% |
| ≥ 1.5 | 22 | 50.0% |

→ 신호 크기와 적중률 사이 일관된 관계 없음. "강한 신호일수록 높은 적중률"이라는 가설 기각.

## 분석 흐름

```
[질문]
VIX slope이 BTC와 관계 있다는 논문 발견.
slope의 "수준"이 아니라 "일별 변화량(slope_change)"이 더 강한 신호 아닐까?
              ↓
[가설]
slope_change(T) > 0 → 다음 미국 장중 BTC 상승 (Long)
slope_change(T) < 0 → 다음 미국 장중 BTC 하락 (Short)
              ↓
[T-day 시간축 도입]
slope_change(T)는 T-day 0:00 직전에 확정.
T-day의 모든 측정 시점이 그 이후 → lookahead-free.
              ↓
[검증 — 3가지 방법]
1. 다음 장중 적중률 (slope_change 본래 가설)
   → IS 50.5%, OOS 50.4%, ALL 50.5%
2. T-day 윈도우 분 단위 적중률 (1,035개 시점)
   → 평균 ~47%, 어디서도 유의한 예측력 없음
3. |slope_change| 크기별 적중률
   → 모든 크기 구간에서 48~51% 수준
              ↓
[결론]
slope_change는 BTC 방향 예측 신호로 사용 불가.
논문의 "시차 예측력 없음" 결론과 일치.
```

## vix_duration 분석과의 비교

| 항목 | vix_duration | slope_change (본 분석) |
|------|-------------|---------------------|
| 예측 변수 | ΔVIX% (연속) | sign(slope_change) (부호) |
| 시간축 | T-day | T-day (동일) |
| 종속 변수 | T-day 분 단위 BTC 누적 | T-day 분 단위 + 다음 장중 |
| 결론 | 예측력 없음 (적중률 47.5%) | 예측력 없음 (적중률 50.5%) |

두 분석 모두 **VIX 기반 시차 예측은 성립하지 않음**을 독립적으로 확인했다.
