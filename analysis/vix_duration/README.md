# VIX Duration 분석 (VIX → BTC 영향력 유효시간)

> 최종 업데이트: 2026-06-02 (T-day 시간축 적용)
> 핵심 질문: **"VIX 변화가 BTC에 얼마나 오래 남아 거래 가능한 예측 신호가 되는가?"**
> **최종 결론: T-day 윈도우 전 구간 방향 예측력 없음 (적중률 ≈ 47.5%). VIX→BTC는 동시적 관계만 강하다.**

---

## 시간축 정의 — T-day

본 분석은 **T-day 시간축**을 사용한다. 각 거래일을 0:00에 시작하는 새로운 시간 단위로 재정의:

```
T-day 0:00  ≡  절대 시각 16:16 ET (VIX 종가 확정 직후 첫 BTC 측정)
T-day 17:14 ≡  절대 시각 익일 09:30 ET (다음 미국 시장 개장)
```

| T-day 표현 | 절대 시각 |
|----------|----------|
| T=0 의 0:00 | 2024-01-02 16:16 ET |
| T=0 의 17:14 | 2024-01-03 09:30 ET |
| T=1 의 0:00 | 2024-01-03 16:16 ET |
| ... | ... |

이 시간축에서 ΔVIX%(T)는 T-day 0:00 직전에 확정되고 BTC[T, t]는 t > 0:00에서만 측정되므로, **lookahead bias가 시간축 정의로부터 구조적으로 불가능**하다.

## 분석 흐름

```
[질문]
VIX 종가는 T-day 0:00 직전에 확정된 후 17:14까지 동결된다.
BTC는 그 사이에도 24시간 거래된다.
=> ΔVIX는 T-day 윈도우 동안 BTC 방향을 예측할 수 있는가?
              ↓
[설계]
T-day 시간축 도입:
  ΔVIX(T)는 T-day 0:00에 확정 (예측 변수)
  BTC[T, t]는 t > 0:00에서 측정 (종속 변수)
  => 예측 변수가 시간상 항상 선행 → lookahead-free
              ↓
[측정]
T-day 0:00 ~ 17:14의 각 분 단위 시점에서
  Pearson 상관 r과 방향 적중률 hit% 계산
              ↓
[결과 — 기본 구간 2024-01~2026-04, 601 T-day]
- 상관 r: 0 부근, 전 구간 약함 (최강 T-day 1:04에서 r=-0.105, p=0.010)
  - Bonferroni 보정 시 어느 시점도 통과 못함
- 방향 적중률: 평균 47.5% (50%가 무작위 기준)
- 동시 벤치마크: r = -0.233 (강함, 그러나 거래 불가)
              ↓
[결론]
VIX→BTC는 장중 동시적으로만 강하다.
정보가 T-day 0:00 이전에 이미 BTC 가격에 흡수됨.
T-day 윈도우 방향 예측 채널 없음 → 거래 불가.
```

## 핵심 수치 요약

| 항목 | Primary (2024-2026) | Supplementary (2020-2023) |
|------|---------------------|---------------------------|
| 표본 | 601 T-day | 1,017 T-day |
| 동시 벤치마크 r | -0.233 (p=7.4e-09) | -0.180 (p=7.3e-09) |
| T-day 평균 적중률 | **47.48%** | **49.65%** |
| 가장 강한 음의 r | -0.105 (T-day 1:04) | -0.185 (T-day 3:17) |
| p<0.05 시점 비율 | 1.0% (10/1035) | 88.4% (915/1035) |
| Bonferroni 통과 | 없음 | 일부 |

**핵심 통찰**: 추가 구간은 상관계수가 매우 유의하지만 (r = -0.180, p = 7.3×10⁻⁹), 방향 적중률은 여전히 50% 부근이다. **상관 유의 ≠ 방향 예측력** — 이는 변동성 동조이지 방향 예측이 아니다.
