논의지점 1

장초 포지션: Binary Slope → HMM 3-State

초안 vs 수정안 비교

🔴 초안 구조 (현재)
VIX slope = VIX_9d - VIX_30d
  > 0 (역전) → Short
  < 0 (정상) → Long

slope가 +0.01이든 +5이든 동일하게 Short — 강도 정보 소실

🟢 수정안 구조
HMM → 3개 State 진단
  공포(Fear)   → Short 강한 베팅
  경계(Alert)  → 소규모 Short or 관망
  정상(Normal) → Long

slope의 크기·패턴을 모두 반영

정합성 평가

✅ 이론적 정합성: 높음

초안의 binary slope는 논문(VIX to BTC)의 PCA2 Slope 효과를 극단적으로 단순화한 것입니다. 논문 자체도 slope의 크기(magnitude)가 중요하다고 시사하며:

  • slope = 0.1 (미세 역전) vs slope = 5.0 (극단적 패닉) → 동일 포지션은 비효율적
  • HMM 3-state는 이 강도 차이를 구조적으로 포착 가능
  • HMM이 VIX 기반 regime 분류에 실증적으로 우수함이 검증된 방법론

⚠️ 실무적 고려사항

항목 Binary Slope HMM 3-State
구현 복잡도 낮음 (수식 1줄) 중간 (hmmlearn 학습 필요)
과적합 위험 거의 없음 학습 데이터 선택에 민감
해석 가능성 높음 높음
4주 일정 내 구현 ✅ ✅ (hmmlearn 기존 스택 포함)
slope 연속성 활용 ❌ ✅
State 레이블 일관성 N/A ⚠️ 학습마다 State 순서 바뀔 수 있음

⚠️ 핵심 리스크: HMM State 고정

왜 State 번호가 바뀌는가

HMM은 내부적으로 EM 알고리즘으로 학습합니다. EM은 무작위 초기값에서 시작해 수렴하는 방식이기 때문에, 같은 데이터로 두 번 학습해도 State에 붙는 번호가 달라질 수 있습니다.

1번째 학습
State 0 → VIX avg 12 (정상)
State 1 → VIX avg 22 (경계)
State 2 → VIX avg 38 (공포)
2번째 학습 (같은 데이터)
State 0 → VIX avg 38 (공포) ← 뒤바뀜
State 1 → VIX avg 12 (정상)
State 2 → VIX avg 22 (경계)
왜 문제가 되는가
🔴 전략이 반대로 작동할 수 있음

코드에 if state == 2: Short로 하드코딩했을 때, 재학습 후 State 2가 "경계"로 바뀌면 전략이 완전히 뒤집힙니다.

해결: VIX level 평균으로 정렬 후 고정

각 State에 속한 날들의 VIX_30d 평균을 기준으로 번호를 강제 재정렬합니다.

import numpy as np

# 1. HMM이 예측한 State 시퀀스
raw_states = hmm.predict(features)

# 2. 각 State의 VIX_30d 평균 계산
state_vix_means = []
for k in range(3):
    mask = (raw_states == k)
    mean_vix = vix_30d_level[mask].mean()
    state_vix_means.append((k, mean_vix))

# 3. VIX 평균 오름차순 정렬
sorted_states = sorted(state_vix_means, key=lambda x: x[1])

# 4. 매핑 테이블 생성 (낮은 VIX=정상, 중간=경계, 높은 VIX=공포)
STATE_MAP = {
    sorted_states[0][0]: 'normal',
    sorted_states[1][0]: 'alert',
    sorted_states[2][0]: 'fear',
}
# 예: {1:'normal', 2:'alert', 0:'fear'} ← 번호가 달라도 레이블 일관

# 5. 추론 시
state_label = STATE_MAP[hmm.predict(today_feature)]

최적 대안 추천

✅ HMM 3-State 채택 + Binary Slope를 Fallback으로 유지
구현 순서: 1. pca1, pca2, delta_slope, vix_30d_level → HMM 학습
2. STATE_MAP으로 State 레이블 고정
3. 포지션 매핑 [거래 수단: BTC 현물]:

논의지점 2

장중 이상탐지: VXX(ETN) 대안 모색

초안의 VXX 사용 논리

VIX 분봉 없음 (CBOE는 일봉만 무료) → VXX(ETN)을 VIX 실시간 대리변수로 사용 → LSTM AE 입력: VXX 1분봉 + BTC 초봉

문제점

🔴 ETN 구조적 리스크
  • 발행자 신용 리스크: Barclays 발행 — 부도 시 가치 0 가능
  • 2022년 사례: Barclays 구조화 상품 발행 한도 초과 → VXX 신규 발행 중단 → 기초자산(VIX 선물) 대비 30%+ 프리미엄 발생 → 전략 신호 자체가 왜곡됨
⚠️ VXX 구조적 약점 (ETN/ETF 공통)
  • 롤오버 비용(Contango): VIX 선물 만기 롤오버 시 장기 하락 편향 내재 → 레벨 비교 절대 금지, 방향성 신호로만 활용
  • 단기(분봉) VIX와의 상관계수는 여전히 ~0.9 수준으로 신호 품질 자체는 양호

ETN 괴리율 vs ETF 추적오차 — 리스크 성격 비교

💡 핵심: 두 리스크는 크기보다 성격이 다릅니다

단순히 "추적오차 < 괴리율"이 아니라, 신호 왜곡 여부와 예측 가능성이 근본적으로 다릅니다.

VIXY 추적오차 (ETF) VXX 괴리율 리스크 (ETN)
발생 원인 운용보수 + 롤링 거래비용 발행 한도·신용 이슈로 인한 수급 왜곡
방향 항상 음(−) — 벤치마크 소폭 하회 양방향 — 프리미엄 또는 디스카운트
크기 연 ~0.85% (운용보수) + 수 bp 최대 30%+ (2022년 VXX 사례)
예측 가능성 ✅ 높음 — 사전에 알 수 있음 ❌ 낮음 — 언제 터질지 모름
지속 기간 지속적·안정적 드리프트 수개월 지속 가능
분봉 신호 왜곡 ✅ 거의 없음 ❌ 직접 오염 가능
자동 괴리 해소 AP 차익거래로 자동 축소 ❌ 발행 중단 시 해소 불가
📌 AP = Authorized Participant (지정참가회사) — 시계 브랜드 아님

ETF 시장에서 AP는 ETF 설정·환매를 통해 괴리율을 자동으로 줄이는 기관투자자를 뜻합니다.

상황 AP의 행동 결과
시장가 > NAV (프리미엄) VIX 선물 매입 → ETF 신규 설정 → 시장에 매도 공급 증가 → 시장가 하락 → 괴리 해소
시장가 < NAV (디스카운트) 시장에서 ETF 매수 → 운용사에 환매 → 선물 수령 공급 감소 → 시장가 상승 → 괴리 해소

이 차익거래 메커니즘이 존재하기 때문에 ETF 괴리율은 구조적으로 작게 유지됩니다.
ETN에는 AP가 없고 발행사가 직접 공급 조절을 하므로, 발행 한도 소진 시 해소 수단이 없습니다.

추적오차가 분봉 신호에 영향이 없는 이유
추적오차 = 연간 0.85% 수준의 하향 드리프트
→ 하루 환산 약 0.003%
→ 1분봉 VIX 움직임(수% 단위)에 비하면 무시 가능
→ VIX 선물이 오르면 VIXY도 거의 동일하게 오름 (방향성 보존)
VXX 괴리율이 신호를 오염시키는 예시 (2022년)
📌 LSTM AE 이상 신호의 실체 — 먼저 이해해야 할 것

LSTM AE는 VXX 단독이나 BTC 단독을 보는 게 아닙니다.
정상 구간에서의 VXX-BTC 공동 패턴을 학습하고, 그 관계가 무너질 때 이상 신호를 냅니다.

학습 패턴 (정상 구간) 이상 신호 발생 조건
VXX 상승 ↔ BTC 하락 이 관계에서 벗어나는 VXX-BTC 조합 → reconstruction error 상승
VXX 안정 ↔ BTC 횡보
🔴 실제 신호 오염 시나리오 (2022년 VXX 발행 중단)
VIX 선물 하락 → 실제 공포 해소 → BTC 안정 또는 상승
↓
ETN 발행 중단으로 VXX 시장가는 프리미엄 유지 → 여전히 높음
↓
LSTM AE가 보는 상황: "VXX 높음 + BTC 상승"
→ 학습 패턴("VXX 높음 → BTC 하락")과 다름
→ VXX-BTC 관계 괴리로 reconstruction error 상승 → 이상 신호 발생
↓ 실제로는 공포 해소 구간인데 허위 경보 반복 발생
❌ 이전 설명 (부정확)

"VXX가 비정상적으로 높다 → 이상 신호"
→ VXX 단독 수준 문제로 잘못 설명

✅ 정확한 설명

"VXX 높음 + BTC 상승"이 학습 패턴과 달라
→ VXX-BTC 관계 괴리가 이상 신호의 실체

✅ VIXY로 교체 시 해결되는 이유

VIXY는 VIX 선물 가격을 충실히 반영하므로, VIX 선물 하락 시 VIXY도 하락합니다.
→ 가짜 VXX-BTC 괴리 자체가 발생하지 않음 → 허위 이상 신호 없음

ETN 괴리율의 실제 발생 원인

발행사의 계산 오류나 지연이 아니라 수급 구조 문제입니다:

원인 메커니즘 심각도
발행 한도 소진 추가 발행 불가 → 공급 조절 수단 상실 → 프리미엄 폭등 매우 높음
발행사 신용 위기 투자자 기피 → 매도 압력 → 디스카운트 높음
유동성 부족 장세 스프레드 확대 → 체결가 IV 이탈 중간 (일시적)
거래 중단 구간 IV는 계속 계산되나 시장가 미업데이트 → 재개 시 갭 중간 (일시적)
⚠️ 공통 리스크: Contango 드리프트 (ETF·ETN 동일)

VIXY도 VXX와 동일하게 VIX 선물 기반이므로 Contango 롤오버 비용이 발생합니다.
→ 레벨 비교 금지 원칙은 VIXY에도 그대로 적용됩니다. 장중 방향성 신호로만 활용.

추가 고려: HMM State ↔ LSTM AE 연계

💡 두 수정안의 연동 설계 가능

HMM State에 따라 LSTM AE의 이상탐지 임계값을 동적으로 조정하면 False Positive를 줄이면서 민감도를 높일 수 있습니다.

State=fear → 임계값 낮춤 (이상 탐지 민감도 ↑, 공황 시 빠른 반응)
∂ State=alert → 임계값 기본 State=normal → 임계값 높임 (False Positive 억제)

→ 두 수정안이 단순히 독립적 변경이 아니라 서로 연동되는 구조로 설계 가능. 현재는 분리 운영 후 추후 검토.
