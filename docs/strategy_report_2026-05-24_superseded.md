### 2.8 장중 개입 실패의 근본 원인

12가지 장중 개입이 모두 실패한 이유를 구조적으로 정리한다.

| 개입 유형          | 시도한 방법                        | 실패 원인 |

| 포지션 전환/청산   | LSTM-AE anomaly                    | anomaly와 slope 실패가 독립적 |
| 레버리지 동적 조절 | anomaly score, GARCH, vol-targeting | BTC 장중 변동성에 일별 지속성 없음 |

## 3. LSTM-AE 활용 방안: 잔차 분해 + 강건성 검증

LSTM-AE가 직접 Alpha를 생성하지는 못했지만, 두 가지 방면에서 전략에 기여한다.

### 3.1 잔차 분해 분석 — 약한 방향 정보 존재

anomaly가 발생한 시점에서, 각 피처의 signed residual을 계산:

```
signed_residual = actual - reconstructed
양수: 실제 값이 모델 예측보다 높음
음수: 실제 값이 모델 예측보다 낮음
```

**피처별 상관 결과:**

| 피처                  | IS r (15분) | OOS r (15분) | 해석 |
| **btc_return**        | **+0.247** | **+0.081** | BTC가 예상 외 상승 -> 계속 상승 (모멘텀) |
| **trade_imbalance**   | **+0.108** | **+0.087**  | 매수 우위 -> BTC 상승 |
| vixy_return           | -0.036   | -0.046    | VXX 예상 외 상승 -> BTC 하락 |
| avg_trade_size        | -0.034   | -0.020     | 대형 거래 -> BTC 하락 |

**방향 예측 정확도:**

| 예측 규칙                        | IS 정확도  | OOS 정확도 | 판정 |
| BTC 잔차 모멘텀 (양수->Long)     | **57.1%**  | **54.3%**  | 약하지만 IS/OOS 일관 |
| VXX 잔차 반전 (양수->Short)      | 51.2%      | 53.1%      | 약함 |

**판정**: BTC 잔차 모멘텀(54.3% OOS)은 통계적으로 유의미하나, 단독 트레이딩 신호로 사용하기에는 **너무 약하다.** 향후 다른 신호와의 결합 가능성은 열려 있으나, 현재 확정 전략에는 포함하지 않는다.

### 3.2 강건성 검증 도구로서의 역할

**왜 강건성 검증이 필요한가:**

VIX slope_change 전략이 실전에서 작동하려면, VXX-BTC 간의 미시적 관계가 일시적으로 깨지는 구간에서도 slope 신호가 유효해야 한다. LSTM-AE가 정확히 이 질문에 답을 준다.

**검증 결과:**

- LSTM-AE가 anomaly로 판정한 구간(VXX-BTC 관계 이탈)에서도, slope_change 방향은 **60%가 양수** (정상 구간과 유사)
- anomaly 구간 수익률: **+0.87bp/분** vs 정상 구간: +0.80bp/분 (오히려 유사~양호)
- anomaly 구간 변동성은 1.3~1.4x 높지만, slope 신호 실패율은 증가하지 않음

**의미:**

VXX-BTC 미시적 관계가 일시적으로 깨져도, VIX 기간구조라는 **거시적 신호**는 BTC 장중 방향을 계속 맞추고 있다. 이는 slope_change 신호가 특정 시장 상황에서만 작동하는 것이 아니라 **구조적으로 강건(robust)**하다는 간접 증거이다.

LSTM-AE는 Alpha를 직접 생성하지 못했지만, 전략의 실전 배포 신뢰도를 높이는 데 기여했다.

## 4. 확정 전략 상세 설명

### 4.1 핵심 아이디어: VIX 기간구조의 일일 변화가 BTC 장중 방향을 결정

VIX에는 만기가 다른 여러 선물이 존재한다. 단기 VIX와 중기 VIX3M의 차이를 **slope**라고 정의한다.

```
slope = VIX3M - VIX
```

- **slope > 0 (contango)**: 시장이 단기보다 중기를 더 불안하게 봄. 정상 상태.
- **slope < 0 (backwardation)**: 단기가 중기보다 높음. 지금 당장 공포가 큰 상태.

논문(Luo, Tsai & Yen 2026)은 이 slope의 **수준(level)**이 BTC 수익률을 설명한다고 보고했다. 우리의 핵심 발견은 slope의 **일일 변화율(slope_change)**이 장중 방향 예측에 훨씬 강력하다는 점이다.

```
slope_change = 오늘 slope - 어제 slope
```

| 신호 유형                       | OOS 방향 정확도 | 비고 |
| slope 수준 (논문 방식)          | 52.2%           | 동전 던지기 수준 |
| **slope 변화율 (우리 발견)**    | **65.0%**       | 필터 없이 전 거래일, 123일 |

이것은 논문을 넘어서는 발견으로, 프로젝트의 주요 기여이다.

### 4.2 방향 결정 로직

```
slope_change > 0  →  Long BTC (매수)
slope_change < 0  →  Short BTC (매도)
```

**방향 로직의 경제학적 근거:**

- **slope_change > 0 (Long)**:
  slope이 커지는 중 = contango 심화 = VIX 기간구조가 정상화되는 방향.
  단기 공포(VIX)가 중기(VIX3M) 대비 상대적으로 줄어들고 있다는 의미.
  이는 **risk-on** 분위기를 반영 -> BTC 상승 가능성 높음 -> **Long**.

- **slope_change < 0 (Short)**:
  slope이 줄어들거나 역전 방향 = backwardation 방향으로 이동 중.
  단기 VIX가 상대적으로 더 올라감 = 단기 공포 증가.
  이는 **risk-off** 분위기를 반영 -> BTC 하락 가능성 높음 -> **Short**.

### 4.3 매일 거래 + 4단계 레버리지 스케일링

초기 실험에서는 |slope_change| < 0.5인 날을 필터링(관망)했으나, 매일 거래하는 방식으로 전환했다. 약한 신호에는 낮은 레버리지를 배정하여 리스크를 관리한다.

```
|slope_change| >= 1.5  →  10x (매우 강한 신호)
|slope_change| >= 1.0  →   5x (강한 신호)
|slope_change| >= 0.3  →   3x (보통 신호)
|slope_change| <  0.3  →   1x (약한 신호)
```

**왜 필터 제거 + 4단계 스케일링인가?**

| 방식                            | OOS Net     | Sharpe   | MDD      | 거래일   |
| 필터(sc>=0.5) + 2단계(3x/2x)   | +197.4%     | 7.74     | -19.3%   | 50일     |
| **매일 + 4단계(10/5/3/1)**      | **+457.6%** | **5.31** | **-29.0%** | **123일** |

매일 거래 시 Sharpe는 다소 낮아지지만, 총 수익이 2.3배 증가하고 거래 기회가 2.5배 늘어난다.

**4단계 레버리지 스케일링의 효과:**

slope_change의 크기(절대값)가 클수록 신호가 강하고, 실제로 승률과 수익이 높아지는 것이 IS/OOS 모두에서 확인되었다.

| \|slope_change\| 범위        | IS 승률  | OOS 승률 | OOS 일평균 수익 |
| 0.50 ~ 0.68 (약한 신호)     | 77%      | 72%      | +2.29%       |
| 0.68 ~ 0.89 (중간 신호)     | 68%      | 68%      | +1.42%       |
| **0.89 이상 (강한 신호)**    | **79%**  | **88%**  | **+5.60%**   |

이 패턴이 강한 신호에 고레버리지를 배정하는 근거이다.

**고레버리지 후보 비교 (OOS, 4단계 통일):**

| 전략                  | Net      | Sharpe   | MDD      | 평균 레버리지 |
| 8/5/3/1               | +428%    | 5.22     | -29.0%   | 2.59x     |
| **10/5/3/1 (확정)**   | **+458%** | **5.31** | **-29.0%** | **2.69x** |
| 15/8/4/1              | +674%    | 5.25     | -38.7%   | 3.64x         |
| 20/10/5/1             | +859%    | 5.26     | -48.3%   | 4.51x         |

10/5/3/1이 **Sharpe 최고(5.31)이면서 MDD -29%로 통제 가능한 수준**이다. 15x 이상은 MDD가 -39%~-48%로 급증하며, 20x는 IS에서 MDD -99%로 사실상 파산 리스크가 존재한다.

### 4.4 매매 타이밍: 장 시작 진입, 마감 청산, 장중 무개입

```
09:30 ET (미국 장 시작)  →  포지션 진입
09:31 ~ 15:58 ET         →  아무것도 안 함
15:59 ET (장 마감 1분 전) →  전량 청산
```

**왜 장중에 아무것도 안 하는가?**

이 프로젝트에서 장중 개입을 위한 **12가지 이상의 방법**을 시도했고, **전부 실패**했다 (상세: 섹션 2).

근본적 이유: VIX slope은 **일봉 레벨의 신호**이다. 이 신호가 하루 전체를 지배하며, 장중 분봉 레벨의 어떤 추가 정보(anomaly, 미시구조, 변동성, 가격 패턴)도 이를 개선하지 못한다. 장중 최고점이 발생하는 시간도 균등 분포이므로, 최적 청산 시점 예측 자체가 불가능하다.

**결론: 하루 의사결정 1번, 거래 2번(진입+청산), 나머지 시간은 방치. 이것이 28개월 데이터에서 검증된 최적 구조이다.**

### 4.5 비용 구조

```
수수료:     Taker 0.05% per side (진입 + 청산)
슬리피지:   5bp per side (보수적)
레버리지:   1x ~ 10x (4단계)

1회 거래 왕복 비용 (레버리지별):
  1x:  (0.05% + 0.05%) x 2 sides x  1x = 0.20%
  3x:  (0.05% + 0.05%) x 2 sides x  3x = 0.60%
  5x:  (0.05% + 0.05%) x 2 sides x  5x = 1.00%
  10x: (0.05% + 0.05%) x 2 sides x 10x = 2.00%
```

10x 거래 시 왕복 비용이 2.00%로 높지만, |slope_change| >= 1.5인 날의 평균 수익이 +5.60%이므로 비용 대비 충분히 정당화된다.

### 4.6 하루 운영 루틴

```
장 시작 전 (08:00~09:29 ET):
  1. CBOE에서 VIX, VIX3M 전일 종가 확인
  2. slope = VIX3M - VIX 계산
  3. slope_change = 오늘 slope - 어제 slope 계산
  4. 레버리지 결정:
     |sc| >= 1.5  →  10x
     |sc| >= 1.0  →   5x
     |sc| >= 0.3  →   3x
     |sc| <  0.3  →   1x
  5. slope_change > 0 → Long / < 0 → Short

09:30 ET:
  6. BTCUSDT 영구 선물 진입

09:31 ~ 15:58 ET:
  7. 아무것도 안 함

15:59 ET:
  8. 전량 청산
```

### 4.7 비교군 대비 성과 (OOS)

| 항목            | B1: 3x Long 고정         | B2: slope+3x 고정      | **실험군 10/5/3/1** |
| 전략 설명        | 방향 없이 매일 3x 롱        | slope 방향 + 고정 3x    | slope 방향 + 4단계 스케일링   |
| Net Return     | -164.1%                 | +306.8%               | **+457.6%** |
| Alpha (vs B2)  | -                       | 0                     | **+150.8%p** |
| Sharpe         | -2.19                   | 4.44                  | **5.31** |
| Hit Rate       | 41.9%                   | 65.0%                 | 65.0% |
| MDD            | -192.5%                 | -43.7%                | **-29.0%** |
| 평균 레버리지     | 3.00x                   | 3.00x                 | **2.69x** |
| 승 평균 수익      | -                       | +7.17%                | **+8.06%** |
| 패 평균 손실      | -                       | -6.20%                | **-4.36%** |

**핵심: 평균 레버리지가 더 낮으면서(2.69x < 3.00x) 수익은 더 높고 MDD는 더 낮다.**
강한 신호에 집중 배팅하고 약한 신호에 방어하는 구조가, 동일 레버리지 고정 대비 모든 지표에서 우월하다.

### 4.8 IS/OOS 구간 설계

Constitution 기준 80/20 시간순 분할을 적용한다.

| 구간  | 기간                     | 거래일 수   | 비율  | 용도 |
| IS   | 2024-01-15 ~ 2025-10-31 | ~460일    | 79%  | 모델 학습, 파라미터 탐색 |
| OOS  | 2025-11-01 ~ 2026-04-30 | ~125일    | 21%  | 최종 1회 평가 |

OOS 데이터는 최종 1회 평가에만 사용. 파라미터 탐색 중 OOS 접근 시 해당 실험 결과 전면 무효 처리.

## 6. 팀 논의 필요 사항

1. **HMM 팀과의 통합**: HMM Phase A(일봉 레짐) + LSTM-AE Phase B(장중) 연동 방식. 우리 실험 결과 장중 개입은 모두 실패했으므로, Phase B 역할을 "강건성 검증"으로 재정의 제안
2. **레버리지 상한**: 10x (현재 확정) vs 15x (MDD -39% 감수) -- 리스크 허용 범위
3. **LSTM-AE 보고서 포함 범위**: 강건성 검증 + 잔차 분해까지 vs 강건성만
4. **잔차 분해 신호 활용**: 54.3% OOS 정확도를 HMM 또는 다른 모델과 결합할 가치가 있는지
