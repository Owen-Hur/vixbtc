# 전체 파이프라인 시뮬레이션 예시

이 문서는 프로젝트의 전체 흐름을 가상 수치로 시뮬레이션한 예시입니다.
구조와 흐름은 실제 구현과 동일하며, 수치는 설명 목적의 가상값입니다.

## Phase 2: LSTM Autoencoder 학습

### Step 2-1: 학습/테스트 분할 (Walk-forward)

```
Walk-forward 1차 (관세 전 학습 -> 관세 후 테스트):
  학습:   2024.01 ~ 2025.04 (관세 전) -> 약 15만 행
  테스트: 2025.04 ~ 2026.04 (관세 후) -> 약 9만 행
  검증:   관세 전 시장에서 학습한 모델이 관세 후에도 작동하는가?

Walk-forward 2차 (관세 후 학습 -> OS 테스트):
  학습:   2025.04 ~ 2026.04 (관세 후) -> 약 9만 행
  테스트: 2026.05 OS 구간 (실시간 수집 약 3주) -> 약 6000행
  검증:   최근 시장으로 학습한 모델의 실전 적용 가능성
```

### Step 2-2: Window 생성

```
학습 데이터에서 60분 window를 슬라이딩으로 생성:

  window_0: [09:31 ~ 10:30] x 7피처 = 60x7 행렬
  window_1: [09:32 ~ 10:31] x 7피처 = 60x7 행렬
  window_2: [09:33 ~ 10:32] x 7피처 = 60x7 행렬
  ...

  주의: 날짜가 바뀌는 경계는 제외 (어제 15:59 + 오늘 09:30이 섞이면 안 됨)
  피처 7개: btc_return, imbalance, count, avg_size, vxx_return, vxx_std, vxx_btc_corr
  VIX slope는 window에 넣지 않음 (방향 결정용이지 이상 탐지용이 아님)

  총 window 수: 약 12만 개
```

### Step 2-3: 모델 학습

```
LSTM Autoencoder 구조:
  인코더: LSTM(64) -> LSTM(32) -> latent vector (32차원)
  디코더: LSTM(32) -> LSTM(64) -> Dense(7)

  입력: 60 x 7 행렬
  출력: 60 x 7 행렬 (입력을 복원)
  손실함수: MSE (입력과 출력의 차이)

학습 과정 (약 50 epoch):
  Epoch 1:  loss = 0.0842
  Epoch 10: loss = 0.0231
  Epoch 20: loss = 0.0098
  Epoch 30: loss = 0.0054
  Epoch 40: loss = 0.0041
  Epoch 50: loss = 0.0038  <- 수렴

  학습 시간: GPU ~10분, CPU ~1시간
```

### Step 2-4: 임계값 설정

```
학습 데이터 12만 window -> 12만 개의 anomaly score

정상 window (60분) score 분포:
  min:    0.0002
  25%:    0.0015
  50%:    0.0028
  75%:    0.0045
  90%:    0.0067
  92.5%:  0.0078   <- 상위 7.5% = 임계값
  95%:    0.0092
  max:    0.0834

  정상 window 임계값: 0.0078

장 초반 (09:45~10:29) 짧은 window score 분포:
  50%:    0.0058    <- 정상 window보다 높음 (데이터 적어 복원 에러 큼)
  92.5%:  0.0145   <- 상위 7.5% = 장 초반 임계값

  장 초반 임계값: 0.0145 (정상 window의 약 1.9배)

검증:
  정상 window: 이상 판정 비율 = 7.5%
  장 초반:     이상 판정 비율 = 7.5%
  -> 두 구간 모두 동일한 이상 판정 빈도 유지
```

## Phase 3: 백테스트 (Walk-forward 1차)

### Step 3-1: 하루 시뮬레이션 예시 (2025-05-15)

```
장 시작 전:
  VIX slope (PCA2) = +1.85 (양수 = 역전)
  -> 기본 방향: Short

09:30  Short 진입 @ 67,250.0
       (슬리피지 15bp -> 실질 진입가: 67,239.9)

09:30~09:44  데이터 축적 중, score 없음, Short 유지

09:45  window=15분, score=0.0082 < 0.0145 -> 정상, Short 유지
09:50  window=20분, score=0.0095 < 0.0145 -> 정상
10:00  window=30분, score=0.0125 < 0.0145 -> 정상

10:15  window=45분, score=0.0168 > 0.0145 -> 이상 탐지!
       확인:
         1단계: anomaly score 초과
         2단계: trade imbalance +0.45 (매수 압력 = Short과 반대)
       -> 포지션 교체: Short 청산 + Long 진입
       Short 청산 @ 67,180.0 -> 수익 +0.10%
       Long 진입 @ 67,180.0 (슬리피지 15bp 적용)
       교체 비용: 수수료 0.05% 왕복 + 슬리피지 15bp = 0.20%

10:16~10:19  최소 보유 5분 -> 교체 불가

10:20  score=0.0152 > 0.0078 -> 이상 지속, Long 유지
10:31  score=0.0062 < 0.0078 -> 이상 해소!
       -> 기본 방향(Short)으로 복귀
       Long 청산 @ 67,220.0 -> 수익 +0.06%
       Short 재진입 @ 67,220.0
       복귀 비용: 0.20%

12:00 ET (= 16:00 UTC):
       펀딩비 정산 시점
       Short 포지션 보유 중
       펀딩비율: +0.01% (Long -> Short 지불)
       -> Short이므로 펀딩비 수취: +0.01%

15:59  장 마감 청산 @ 66,950.0
       Short 수익: +0.40%
```

### 하루 정산

```
포지션 수익 (레버리지 2배):
  (+0.10% + 0.06% + 0.40%) x 2 = +1.12%

비용:
  수수료 + 슬리피지: 4회 x 0.20% = -0.80%
  펀딩비: +0.01% (수취)

당일 순수익: +1.12% - 0.80% + 0.01% = +0.33%

비교 전략 (교체 없이 Short 유지):
  수익: +0.45% x 2 = +0.90%
  비용: 2회 x 0.20% = -0.40%, 펀딩비 +0.01%
  순수익: +0.51%

-> 이 날은 비교 전략이 우세 (교체 비용 > 교체 이득)
```

### Step 3-2: 전체 테스트 기간 결과

```
Walk-forward 1차: 2025.04 ~ 2026.04 (약 250거래일)

              우리 전략     비교 전략
누적 수익:     +18.5%       +12.3%
Sharpe:       1.42         0.95
MDD:          -8.2%        -14.7%
일평균 교체:   2.1회         0회
Hit Rate:     58.3%        -
Precision:    62.1%        -

펀딩비:
  Long 보유 시: 95일 x -0.01% = -0.95%
  Short 보유 시: 155일 x +0.01% = +1.55%
  순 펀딩비: +0.60%

거래 비용:
  교체: 525회 x 0.20% x 2 = -2.10%
  진입/청산: 250일 x 2회 x 0.20% = -1.00%
  총 비용: -3.10%
  펀딩비 수취: +0.80%
  순 비용: -2.30%
```

## Phase 4: 분석 및 결론

### 이상 탐지 모델 기여도

```
우리 전략 - 비교 전략 = 모델의 순수 기여도

  수익 차이:    +6.2%p
  Sharpe 차이: +0.47
  MDD 개선:    6.5%p

-> 비용 차감 후에도 +6.2%p 초과수익
-> MDD 개선이 두드러짐 (하락 구간에서 교체 효과)
```

### 한계점

```
1. VXX 분봉 해상도: 초 단위 변동성 전이 포착 불가
2. 장 초반 15분 공백: 09:30~09:44 anomaly score 없음
3. OS 구간 짧음: 약 3주(15거래일), 통계적 유의성 부족
4. 과거 LOB 없음: IS 구간 LOB 필터 미적용
5. 슬리피지 고정값: 변동성 급등 시 15bp 초과 가능
```
